# vmutti.alacritty

Installs and configures the [Alacritty](https://github.com/alacritty/alacritty) terminal emulator and sets it as the system default terminal.

## Roles

- [install](roles/install/README.md) — installs Alacritty, restores per-user configuration, and sets it as the default terminal emulator
