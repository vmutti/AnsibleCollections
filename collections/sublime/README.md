# vmutti.sublime

Installs [Sublime Text](https://www.sublimetext.com) from its official apt repository and restores per-user configuration backups. Integrates with `vmutti.configs.fetch` to back that configuration up.

## Roles

- [install](roles/install/README.md) — adds Sublime's apt repo, installs sublime-text, and restores user configuration
