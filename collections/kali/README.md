# vmutti.kali

Adds the Kali Linux apt repository and keyring to a Debian-based host, then installs a configurable list of Kali security tools/packages (nmap, burpsuite, metasploit-framework, etc). `install.sh` additionally installs [katoolin](https://github.com/LionSec/katoolin) for browsing/installing Kali tool categories interactively.

## Roles

- [install](roles/install/README.md) — adds the Kali repo/keyring and installs kali_packages
