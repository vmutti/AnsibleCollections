# vmutti.autochrome

Installs and runs [NCC Group's Autochrome](https://github.com/nccgroup/autochrome) to harden Chrome/Chromium extension security settings for specified users. `install.sh` provides an equivalent standalone shell-script installer for the current user.

## Roles

- [install](roles/install/README.md) — clones Autochrome and runs it for each user in autochrome_usernames
