# vmutti.burp

Downloads and installs [Burp Suite Professional](https://portswigger.net/burp) for specified users, and restores their saved Burp configuration. Integrates with `vmutti.configs.fetch` to back up that configuration.

## Roles

- [install](roles/install/README.md) — downloads the Burp Suite Pro installer and installs it for each user in burp_usernames
