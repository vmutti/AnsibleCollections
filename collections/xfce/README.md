# vmutti.xfce

Installs the XFCE4 desktop environment and thunar-archive-plugin, and restores system- and user-level configuration backups. Integrates with `vmutti.configs.fetch` to back that configuration up.

## Roles

- [install](roles/install/README.md) — installs xfce4 and restores system/user configuration
