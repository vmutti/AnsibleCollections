# vmutti.terraform

Not yet wrapped as an Ansible role: `install.sh` downloads and installs a pinned legacy release (0.12.23) of the [Terraform](https://www.terraform.io) CLI binary to `/usr/local/bin`.

## Usage

Run `install.sh` on the target host (for example, via Ansible's `script` module) as a user that can `sudo`.
